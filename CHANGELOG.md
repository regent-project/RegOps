# Release v0.7.0

## What's Changed

- CLI introduction with main commands: `run` (service), `config` (management), `run-once` (single pass), and `completion` (shell integration)

## Installation

### Debian/Ubuntu
```bash
sudo dpkg -i ./regops_<version>_amd64.deb
```

### RHEL/CentOS/Fedora
```bash
sudo rpm -i ./regops-<version>.<arch>.rpm
```
